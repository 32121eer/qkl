
# 苹果园数据格式（文档提取汇总）

> 字段列（来自文档表头）：**标识符 / 名称 / 英文名 / 定义 / 数据类型及格式 / 说明**  
> 注：文档中部分“英文名”存在换行/截断（如 *AccumulatedTemp erature*），下表按原文呈现或做最小限度拼接以保持可读性。

---

## 1. 种植环节（Orchard / Cultivation）

| 名称 | 英文名 | 定义 | 数据类型及格式 | 说明 |
|---|---|---|---|---|
| 土壤温度 | SoilTemperature | 土壤的温度 | float |  |
| 土壤湿度 | SoilMoisture | 土壤湿度 | float |  |
| 土壤pH值 | SoilPH | 土壤pH值 | float |  |
| 土壤有机质含量 | SoilOrganicMatter Content | 土壤有机质含量 | float |  |
| 土壤氮磷钾含量 | Soil nitrogen, phosphorus,potassium content | 土壤氮磷钾含量 | float |  |
| 光照时长 | LightDuration | 光照时长 | int |  |
| 降雨量 | Rainfall | 降雨量 | float |  |
| 积温 | AccumulatedTemperature | 积温 | float |  |
| ≥10℃有效积温 | WaterVolume | 水量 | float |  |
| 水质 | WaterQuality | 水质 | float | pH 6.0-7.0 |
| 灌溉方式 | Irrigation method | 灌溉方式 | int | 滴灌/喷灌 |
| 施肥记录 | Fertilization Record | 施肥记录 | string | 有机肥/化肥类型、用量、时间（如花后膨果期追肥） |
| 植保记录 | Plant Protection Records | 植保记录 | string | 农药名称（如毒死蜱≤0.01mg/kg）、施药时间、安全间隔期 |
| 疏花疏果 | Shuhua Shuguo | 疏花疏果 | string |  |
| 物候期 | phenological period | 物候期 | string | 开花期、坐果期、着色期（如片红/条红比例） |
| 果实指标 | Fruit indicators | 果实指标 | string | 横径（≥75mm优质果）、着色度（≥80%）、糖酸比（12-18:1） |

## 2. 采摘环节（Harvest / Picking）

| 名称 | 英文名 | 定义 | 数据类型及格式 | 说明 |
|---|---|---|---|---|
| 成熟度 | maturity | 成熟度 | string | 淀粉指数（碘试法1-7级）、硬度（≥7kgf/cm²）、可溶性固形物（≥12%） |
| 分级标准 | Classification Standard | 分级标准 | string | 按GB/T 10651-2008进行大小/色泽/瑕疵分级（特级果瑕疵≤3%） |
| 采摘时间 | Picking time | 采摘时间 | string | （避开露水时段）、工器具消毒记录（次氯酸钠浓度200ppm） |
| 田间预冷 | Field pre cooling | 田间预冷 | string | 4小时内降温至10℃以下 |

---

## 3. 采后处理环节（Post-harvest Handling）

| 名称 | 英文名 | 定义 | 数据类型及格式 | 说明 |
|---|---|---|---|---|
| 水洗参数 | Washing parameters | 水洗参数 | string | 水温（≤15℃）、消毒剂残留（二氧化氯≤0.3ppm） |
| 光电分选 | Optoelectronic sorting | 光电分选 | string | 糖度（近红外检测）、内部褐变（X光透视） |
| 预冷 | precooling | 预冷 | string |  |

---

## 4. 仓储环节（Storage）

| 名称 | 英文名 | 定义 | 数据类型及格式 | 说明 |
|---|---|---|---|---|
| 气调参数 | Modified Atmosphere Parameters | 气调参数 | string | O₂（2-2.5%）、CO₂（1-2%）、温度（0±0.5℃）、湿度（90-95%） |
| 乙烯控制 | Ethylene control | 乙烯控制 | string | ≤0.05ppm（激光气体分析仪实时监测） |
| 每月检测 | Monthly testing | 每月检测 | string | 硬度下降率（≤0.5kgf/cm²/月）、糖度变化、虎皮病发生率 |
| 库存批次 | batch stock | 库存批次 | string | 入库时间、垛位编号、抽检记录（每垛5%抽样） |

## 5. 运输环节（Transportation）

| 名称 | 英文名 | 定义 | 数据类型及格式 | 说明 |
|---|---|---|---|---|

| 中转仓温湿度日志 | Temperature and humidity log of transit warehouse | 中转仓温湿度日志 | string |  |
